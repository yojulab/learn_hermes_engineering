## 1. 시연 흐름 — 5막 (총 ~12분)

> 각 막: **말할 것 → 보여줄 것 → 실패 시**. 막 사이 전환은 탭 이동뿐이라 끊기지 않는다.

### 1막 — "명단은 이미 알고 있다" (LMS 연동, ~2분)

- **말할 것**: 출결의 원천은 LMS다. 우리는 그걸 1분 주기로 폴링해 당일 명단·강의·퇴실 창을 자동으로 만든다. 판정 기준은 항상 LMS(primary), 카메라는 보조다.
- **보여줄 것**: 대시보드 요약 카드 4종(당일 입실/미퇴실/퇴실 완료/문자) · 강의별 칩(정원 분모) · 미퇴실자 테이블 · 헤더 "퇴실 감시" 뱃지가 **시간표에서 유도된 창**으로 자동 점등되는 것 (`window_source: spring` — 하드코딩 없음)
- **실패 시**: LMS 장애 배너가 뜨면 그 자체를 보여준다 — "마지막 동기화 데이터로 계속 동작한다"는 설계를 말로 전환

### 2막 — "카메라가 본다" (영상 파이프라인, ~1분)

- **말할 것**: 엣지(Jetson)는 송출만, 서버가 당겨온다. 카메라 추가 = `.env` 한 줄, 코드 불변.
- **보여줄 것**: 라이브 뷰에 실시간 화면 · 헤더 카메라 점 초록 · (여유 있으면) `stream_camera.py --help` 한 줄로 "의존성 opencv 하나"를 말로
- **실패 시**: 카메라 점이 희면 **망 배치부터** (`curl /health`) — 아침 체크리스트를 건너뛴 대가다. 복구 불가면 3막을 사전 녹화로 전환하고 "녹화"라고 밝힌다

### 3막 — "누구인지 알고, 판단해서, 문자한다" (핵심 루프, ~4분) ⭐ 클라이맥스

- **말할 것**: 퇴실 태그를 안 찍은 사람(daily_roster 잔존)이 퇴실 시간대 카메라에 잡히면 → 앙상블(ArcFace-R100+AdaFace) 식별 → 본인 강의 퇴실창 게이트 → 복귀 요청 문자. **미등록자·이미 퇴실한 사람은 아무 일도 일어나지 않는다** — 그게 개인정보 설계다.
- **보여줄 것** (순서 고정):
  1. 미퇴실 상태의 팀원(학번 매핑 有)이 카메라 앞에 선다 — 정면 1~1.5m
  2. 실시간 피드에 "📸 포착 — 이름 (유사도%)" 항목이 올라온다
  3. 알람 화면: 해당 건 `REMAINING` 판정 + 발송 상태 + **탐지 사진(서명 URL)**
  4. 팀원 폰에 **[TEST] 복귀 요청 문자 수신** — 폰 화면을 든다
  5. (대조) 이미 퇴실한 팀원이 서면 → 포착은 되지만 `NOT_IN_ROSTER` → 문자 없음. "판정은 카메라가 아니라 명단이 한다"
- **실패 시**: 매칭이 안 되면 억지로 반복하지 않는다 — 알람 화면의 **오늘 쌓인 실제 이력**으로 전환해 같은 흐름을 설명 (2026-08-14 실측 이력이 이미 있다)
- ⚠ 쿨다운 60초 — 같은 사람 재시연은 1분 뒤에

### 4막 — "물어보면 답한다" (LLM 어시스턴트, ~3분)

- **말할 것**: 행정실은 화면을 뒤지는 대신 묻는다. 모델은 아는 게 없고 — **질문에 맞는 조회 도구를 골라 실데이터로만** 답한다(할루시네이션 구조적 차단). 로컬 GPU라 학생 이름이 밖으로 안 나간다.
- **보여줄 것** (3문항 고정):
  1. "오늘 퇴실 안 찍은 사람 누구야?" — 사고 과정이 실시간으로 흐르고, 도구 칩(초록), "상위 N명 + 외 N명" 답변
  2. "○○ 몇 시에 퇴실했어?" — 퇴실 이력 도구, KST 시각으로 답
  3. "내일 날씨 어때?" — "확인할 수 없습니다" (범위 밖 방어 — **일부러 보여준다**, 안전장치 어필)
  - "근거 보기"를 한 번 펼쳐 사고 과정 노출 (검증 가능성 어필)
- **실패 시**: 대용량 질의가 길어지면 스트리밍 진행을 그대로 보여주며 "실시간 계산 중"을 설명 — 멈춘 게 아니라는 걸 델타가 증명한다

### 5막 — "믿을 수 있게 만들었다" (품질·개인정보, ~2분, 슬라이드 중심)

- **말할 것 + 슬라이드**:
  - 정확도: ⬜ **#128 확정 수치로 교체** — 제안: "등록 조건(상한) 95.8%/0.0% · 실배포 조건 78.1%/11.9%, 격차가 곧 남은 과제" (정직한 쌍이 심사 질문에 강하다)
  - 개인정보: 미등록자 미저장 · TTL 자동 삭제 · 사진 서명 URL · test 모드 발송 차단 — "지나가는 사람을 저장하지 않는 시스템"
  - 엔지니어링: 회귀 게이트(±0.0%p 재현 캡처) · 모델 지문 대조 · 세션 분리 실측 8차례 — "수치를 의심하는 프로세스"
- **여기서 끝**: "질문 받겠습니다"
