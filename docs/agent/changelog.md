# 변경이력 (CHANGELOG) — 이슈·코드 일시별 기록

> **목적**: 이슈가 열리고 그에 따라 코드가 수정될 때마다 **일시별로** "무엇이 / 왜 / 전 → 후"를 남기는 살아있는 기록.
> **작성**: AI가 이슈 대응·버그 수정 커밋과 같은 작업 안에서 추가한다. (일반 기능 추가는 커밋 로그로 충분)
> **주의**: 실명·개인정보·시크릿 미포함. 시각은 KST.

---

## 0. 새 항목 기록 양식 (복사해서 2장 타임라인 맨 위에 추가)

```
### YYYY-MM-DD

- **HH:MM** · `커밋해시` · (이슈 #NN) · [영역]
  - **무엇**: 한 줄 요약
  - **전 → 후**: 이전 상태 → 바뀐 상태
  - **왜**: 배경/근거
  - **파일**: 주요 변경 파일
```

영역 태그 예: `[backend]` `[frontend]` `[db]` `[ai]` `[infra]` `[docs]` `[harness]` — 프로젝트에 맞게 조정
