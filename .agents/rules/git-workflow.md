# Git 워크플로우 & 업무 종료 커밋 규약 (Git Commit Rules)

본 문서는 eCare24 프로젝트에서 모든 에이전트가 작업을 수행하고 종료할 때 준수해야 하는 **Git Commit 표준 지침**이다.

---

## 1. 커밋 시점 및 의무 원칙

### 1-1. 업무 종료 시 Git Commit 필수
- 에이전트는 기획 문서 작성, 아키텍처 명세화, 스키마 정의, 룰 수정, 테스트 시나리오 작성 등 **유의미한 업무 단위를 마칠 때마다 반드시 Git Commit을 수행**해야 한다.
- Ralph Loop 실행 중에도 각 마일스톤이나 서브태스크가 완료되면 즉시 커밋하여 디스크 상에 상태를 영속화(State on Disk)한다.

### 1-2. 원자적 커밋 (Atomic Commits)
- 여러 성격의 작업을 한데 뭉뚱그려 커밋하지 않고, 독립적인 기능/문서 단위별로 원자적으로 커밋한다.
- 커밋 전 `git status`와 `git diff`를 확인하여 의도하지 않은 파일이 포함되지 않았는지 점검한다.

---

## 2. 커밋 메시지 컨벤션

커밋 메시지는 다음 접두어를 사용하여 명확히 기술한다:

| 타입 | 의미 | 예시 |
| :--- | :--- | :--- |
| **`arch:`** | 시스템/데이터베이스/폴더 아키텍처 설계 | `arch: PostgreSQL 7대 핵심 DDL 및 폴더 구조 명세 수립` |
| **`docs:`** | PRD, 기획서, 업무지시서, 가이드라인 작성 | `docs: 16개 질환군 4단계 커리큘럼 및 실버 UX 명세 반영` |
| **`feat:`** | 신규 명세, 인터페이스, 템플릿, 스크립트 추가 | `feat: frontend_admin 콜센터 3분할 CTI 인터페이스 정의` |
| **`rule:`** | 하네스 규칙, 에이전트 역할, 스킬 변경 | `rule: eCare24 PRD 사양 및 Git 워크플로우 룰 갱신` |
| **`test:`** | Playwright E2E 검증 시나리오 및 테스트 추가 | `test: 16개 질환군 및 콜센터 화면 무인 캡처 시나리오 작성` |
| **`chore:`** | .gitignore, 환경변수 템플릿, 패키지 설정 | `chore: 4대 프로젝트 .env.example 템플릿 및 launch.json 구성` |

## 3. 커밋 전 보안 및 무결성 체크리스트

1. **`.env` 파일 배제**: 실제 비밀키나 API 토큰이 담긴 로컬 `.env` 파일이 포함되지 않았는가? (`.gitignore` 적용 여부 확인)
2. **비개발 원칙 준수**: 본 단계에서는 실제 소스코드 개발을 진행하지 않으므로, 임의의 소스코드가 아닌 **기획 및 상세 아키텍처 산출물**만 커밋 대상인가?
3. **완료 약속 연계**: Ralph Loop 상태 파일(`.agents/loop/state.json`)의 진전 사항과 커밋 내용이 일치하는가?
