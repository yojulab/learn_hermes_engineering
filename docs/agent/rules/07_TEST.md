### 테스트 데이터 / 외부 의존성 🧩
- 상태: 🧩 기본값
- 결정:
  - E2E는 `<project>_test` DB를 쓰고, 시드 스크립트로 시작 상태를 만든다
  - 실발송·실결제는 테스트 모드(02)로 막는다. 실제 연동 확인이 필요하면 사용자 확인 후 지정 수신자로만
  - 테스트는 개인 `.env`의 기능 스위치에 의존하지 않는다 — 필요한 값은 테스트 설정에서 명시적으로 고정
  - OAuth 등 외부 로그인은 테스트용 우회(세션 주입·테스트 계정)를 둔다

### 자가 검증 루프 🧩
- 상태: 🧩 기본값
- 결정:
  1. 구현 → 서버 재시작 → E2E 실행
  2. 실패 시 스크린샷·콘솔·서버 로그로 원인 파악 → 수정 → 재실행
  3. **최대 5회**. 넘으면 멈추고 (원인, 시도한 수정, 남은 이슈)를 보고
  4. 테스트를 통과시키려고 테스트를 약화·삭제하지 않는다. 기대값을 바꿀 땐 이유를 보고한다
