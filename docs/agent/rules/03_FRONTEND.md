## 4. UI 태그 채번 (의뢰자 소통용) 🧩

- 상태: 🧩 기본값
- 목적: 의뢰자·사용자가 "이 버튼" 대신 **고유 번호**로 화면 요소를 지칭해 피드백할 수 있게 한다
- 결정:
  - 주요 요소(버튼·입력·링크·카드·모달·탭)에 `data-ui-id` 속성 부여
  - 형식: `<영역>-<유형>-<식별>` (대문자, 하이픈) — 예: `PLT-BTN-TEST`, `PLT-INP-DEFAULT`, `COM-LNK-HOME`
    - 영역: 화면/기능 약어 3자 (`COM`=공통 레이아웃, 나머지는 specs/11 화면별로 지정)
    - 유형: `BTN` 버튼 / `INP` 입력 / `SEL` 선택 / `LNK` 링크 / `CRD` 카드 / `MDL` 모달 / `TAB` 탭 / `TBL` 표
    - 식별: 의미 있는 영문 또는 3자리 번호
  - **프로젝트 전체 유니크**. 새 번호는 specs/11의 UI 태그 대장에 등록 후 사용
  - 개발 모드(`.env`의 `NEXT_PUBLIC_SHOW_UI_ID=true` 등)에서만 배지로 표시, **운영 빌드에서는 표시하지 않는다** (속성 자체는 Playwright 셀렉터로 재사용 가능)
