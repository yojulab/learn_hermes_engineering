# 13. 운영 / 런북 (Runbook)

> 문서 상태: 산출물 문서 — **실사용(배포·실데이터·실발송·실결제) 전에 작성**
> **장애가 났을 때 이 문서 하나만 보고 복구할 수 있어야 한다.** 새 장애를 겪을 때마다 2장과 5장에 추가한다.
> ⚠ 주소·계정·토큰의 실제 값을 적지 않는다. 전부 루트 `.env`에 있고, 그 파일은 커밋하지 않는다.
