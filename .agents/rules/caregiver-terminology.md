# 간병 실무 전문 용어 사전 가이드 (Caregiver Clinical Terminology Rules)

- **참조 원본 문서**: [`docs/caregiver_terminology_dictionary.md`](file:///apps/project_ecare24_elearning/docs/caregiver_terminology_dictionary.md) (문서 번호: `ECARE24-GLOSSARY-2026-V1`)
- **적용 대상**: eCare24 플랫폼을 구축하는 모든 하네스 에이전트 (기획, UX, 커리큘럼, CBT, 콜센터 CS, 검증자)

---

## 1. 용어 사전 참조 목적 및 기본 원칙

1. **임상 안전성 및 전문성 보장**:
   - 간병 현장과 병동에서 통용되는 의학·간호 전문 용어 및 현장어(은어/약어)를 정확히 반영하여 환자 안전사고를 방지하고 전문 케어 역량을 표준화한다.
2. **에이전트별 필수 준수 의무**:
   - 모든 에이전트는 교안, CBT 시험 문항, 콜센터 상담 템플릿, UI 문구 생성 시 반드시 본 용어 사전의 **표준 용어, 현장어 및 핵심 수칙(Care Point)**을 최우선 기준으로 준수한다.
   - 임상적으로 위험한 오기재(예: 소변백 위치 역류, 탈건착환 순서 전도, 석션 시간 초과 등)는 결함으로 간주한다.

## 2. 7대 핵심 도메인별 주요 용어 체계

| 영역 | 대표 핵심 용어 (현장어 / 약어) | 표준 용어 및 영문 | 핵심 간병 수칙 (Care Point) |
| :--- | :--- | :--- | :--- |
| **제1장. 거동·의식** | **와상 / 준와상**<br>**건측 / 환측**<br>**섬망 / 석양증후군**<br>**BPSD / 사이드레일** | Bedridden / Semi-bedridden<br>Sound / Affected side<br>Delirium / Sundowning<br>치매 행동심리증상 / 침상 난간 | - **탈건착환 공식**: 벗길 땐 건강한 쪽(건측), 입힐 땐 마비된 쪽(환측).<br>- 자리 비울 때 사이드레일 100% 거치.<br>- 섬망은 치매와 달리 급격 발병·회복 가능. |
| **제2장. 식사·피딩** | **피딩 / 엘튜브 (L-tube)**<br>**위루관 / 펙 (PEG)**<br>**아스피레이션 (오흡인)**<br>**연하곤란 / 토로미 (점도증진제)** | Tube Feeding / Levin tube<br>Percutaneous Endoscopic Gastrostomy<br>Aspiration (흡인성 폐렴 원인)<br>Dysphagia / Food thickener | - 주입 전/중/후 **반좌위(30~45도) 유지** (식후 최소 30분~1시간).<br>- 주입 전 위 잔류량(Residual) 확인 (100ml 이상 시 보류).<br>- 사레 잦은 환자는 토로미로 점도 조절. |
| **제3장. 배설·도뇨** | **폴리 (Foley) / 유린백**<br>**넬라톤 (Nelaton)**<br>**장루 (Colostomy)**<br>**I&O (인앤아웃) / IAD** | 유치도뇨관 / 소변수집주머니<br>단순도뇨 (일회성 배뇨)<br>인공항문 / Stoma<br>섭취·배설량 / 실금관련 피부염 | - **유린백 절대 원칙: 항상 환자의 방광(골반)보다 낮은 위치에 거치** (역류 시 패혈증).<br>- 장루 주머니는 1/3~1/2 찼을 때 비움. |
| **제4장. 체위·이동** | **체변 (체위변경)**<br>**앙와위 / 측위 / 복위**<br>**트랜스퍼 (Transfer)**<br>**슬라이딩보드 / 보행벨트** | Repositioning<br>Supine / Lateral / Prone<br>환자 이승(이동)<br>Transfer Board / Gait Belt | - **체위변경 최소 2시간 주기 준수 (q2hr)**.<br>- 발뒤꿈치 침대판 비접촉(플로팅).<br>- 마비 팔 당기기 금지 (어깨 탈구 위험 → 보행벨트 손잡이 지지). |
| **제5장. 욕창·피부** | **소라 (Bed sore, 욕창)**<br>**발적 (Redness)**<br>**가피 (Eschar) / 삼출물**<br>**폼 드레싱 / 에어매트리스** | Pressure Sore (1~4단계)<br>Erythema (욕창 1단계 신호)<br>괴사 조직 딱지 / 진물(Exudate)<br>Foam Dressing / 공기매트리스 | - 비창백성 발적 발생 시 즉시 체위변경 및 간호사 보고.<br>- 에어매트리스 바닥 닿음(Bottoming-out) 매일 점검. |

| **제7장. 소통·안전** | **노티 (Noti, 의료진 보고)**<br>**바이탈 (Vital Signs, V/S)**<br>**사츄 (SpO2, 산소포화도)**<br>**BST / 억제대 (미튼) / DNR** | Notification (간호사 즉각 구두보고)<br>혈압·맥박·호흡·체온<br>Oxygen Saturation (95% 이상 정상)<br>혈당검사 / 신체보호대 / 연명의료중단 | - **이상 징후 발생 시 1초도 지체 없이 즉시 노티**.<br>- **SpO2 95% 미만 주의, 90% 이하 저산소증 응급 상황**.<br>- 저혈당(70mg/dL 미만) 징후 감시. |

## 3. 현장 압축 "10대 골든 룰" (Golden Rules)

1. **[노티의 원칙]**: 환자 이상 징후는 혼자 판단하지 말고 1초도 지체 없이 간호사에게 알린다.
2. **[사이드레일 원칙]**: 침대 곁을 단 1초라도 떠날 때는 양쪽 침상 난간을 무조건 올리고 잠근다.
3. **[유린백(소변) 원칙]**: 소변 주머니는 무조건 환자의 방광(골반)보다 낮은 침대 하단에 건다.
4. **[탈건착환 원칙]**: 마비 환자 옷을 갈아입힐 때는 '벗을 때 건강한 쪽, 입을 때 마비된 쪽'.
5. **[체변(체위변경) 원칙]**: 와상 환자는 낮과 밤을 불문하고 최소 2시간마다 자세를 바꿔준다.
6. **[피딩(식사) 원칙]**: 콧줄 영양 주입 전/중/후에는 반드시 상체를 30~45도 세워 폐렴을 막는다.
7. **[토로미(점도) 원칙]**: 사레가 잘 들리는 환자는 맹물 대신 점도증진제를 타서 걸쭉하게 마시게 한다.
8. **[석션(흡인) 원칙]**: 가래를 빨아낼 때는 환자의 산소 부족을 막기 위해 1회 15초를 넘기지 않는다.
9. **[사츄(SpO2) 원칙]**: 산소포화도 수치가 95% 미만으로 떨어지면 즉시 위험 신호로 간주한다.
10. **[섬망 대응 원칙]**: 갑자기 헛소리를 하거나 흥분하는 환자는 치매가 아니라 섬망임을 인지한다.

## 4. 병동 차트 및 인계 초고빈도 약어 색인

- **NPO**: 금식 (*Nil Per Os*, 물/약 포함 일체 섭취 금지)
- **BR / ABR**: 침상 안정 (Bed Rest) / 절대 침상 안정 (Absolute Bed Rest)
- **O2**: 산소 요법 (예: O2 2L via cannula)
- **PRN**: 필요 시마다 (*Pro Re Nata*)
- **q2hr**: 매 2시간마다 (예: q2hr 체위변경)
- **tid / bid / qid / hs**: 하루 3회 / 2회 / 4회 / 취침 전
- **f/u**: 추적 관찰 (Follow-up)
- **C/O**: 주호소 증상 (Complains Of)
- **Dx / Op**: 진단명 (Diagnosis) / 수술명 (Operation)
- **CPR**: 심폐소생술 (Cardiopulmonary Resuscitation)

## 5. 하네스 에이전트별 구현 및 검증 체크리스트

| 에이전트 | 담당 구현 및 검증 수칙 |
| :--- | :--- |
| **Caregiver Cert Specialist** | 16대 질환군 교안 및 CBT 시험 문항 출제 시 본 용어집의 표준 용어와 10대 골든 룰을 문제 및 해설의 정답 기준으로 필수 반영. |
| **Silver UX Specialist** | 실버 수강생 포털에서 전문 용어(피딩, 엘튜브 등) 노출 시 직관적인 팝업 툴팁과 오디오 TTS 지원 명세 수립. |
| **Callcenter CS Specialist** | 콜센터 3분할 상담 포털의 상담 템플릿(Alt+1~3) 및 메모장에 NPO, BR, Noti, SpO2 등 약어 자동완성 지원 명세화. |
| **Care Domain Critic** | 생성된 모든 기획 문서에서 소변백 역류, 탈건착환 반대 표기, 석션 시간 초과 등 임상적 오류가 없는지 교차 검증. |
