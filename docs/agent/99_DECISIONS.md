# 99. 결정 변경 이력

> 이미 ✅ 또는 🧩로 확정된 결정을 **변경**할 때만 기록한다. (최초 결정은 각 문서에 기록되므로 여기 쓰지 않는다)
> 목적: 나중에 "왜 이렇게 바꿨더라?"를 추적하고, AI가 과거에 폐기된 방안을 다시 제안하지 않게 한다.
> 🧩 메타 기본값을 업무정의서·사용자 지시로 덮어쓴 경우도 여기 기록한다 (이전 결정 칸에 "🧩 메타 기본값: …").
